# Yamaori Clipper（ブラウザの拡張機能）

vrchat.com で開いたワールドの情報を、自分の PC の Yamaori に保存する。Chrome と Firefox（128 以上）。

## どう取るか

拡張機能は、vrchat.com へ自分から通信しない。vrchat.com のページが自分で受け取った応答（ワールド、ワールドの一覧、本人の情報）を、ページの中で横から見るだけ（`hook.js`）。

| 取り方 | 既定 | 内容 |
|---|---|---|
| 押して保存 | 有効 | ワールドのページや一覧のページに出る「Yamaori に保存」のボタン、または拡張機能のボタンを押したときだけ送る |
| 開いたページから自動で | 切る | ワールドのページや一覧を開くたびに送る。フレンドの一覧も（10 分に 1 回まで）送り、増えた・減った・名前を変えた人を記録する |
| まとめて取る | 切る | Yamaori が知っている、情報のないワールドのページを、押したときだけ裏のタブで 1 つずつ開いて取る（最大 20 件ずつ、10 秒以上の間隔、1 日の上限） |

VRChat の利用規約は、VRChat が出していない道具でデータを取ることを禁じている（13.2(j)）。自動とまとめて取るは、その文面に当たりうるので、使うかどうかは本人が設定で決める。詳しくは [docs/plan.md](../docs/plan.md) の「規約との関係」。

## 入れ方（開発中）

1. Yamaori の WebUI の設定で「ほかのアプリ用のトークン」を作る
2. Chrome: `chrome://extensions` →「デベロッパー モード」→「パッケージ化されていない拡張機能を読み込む」でこのフォルダ。Firefox: `about:debugging` →「一時的なアドオンを読み込む」で `manifest.json`
3. 拡張機能の設定で、Yamaori のアドレス（既定 `http://localhost:47800`）とトークンを入れる

## ファイル

- `hook.js`: ページの中（MAIN）で、ページが受け取った応答を見る
- `content.js`: ページのボタン。届いた応答を覚え、押したとき（または自動）に送るよう頼む
- `background.js`: Yamaori の API へ送る（トークンを付ける）。まとめて取るときのタブを開いて閉じる
- `popup.*`・`options.*`・`bulk.*`: 拡張機能のボタン、設定、まとめて取る画面
