## 一覧と違った

- **`User Authenticated: 名前 (usr_…)` は出ない**。本人の名前と ID は `[Authentication - …] Preforming post login checks for 名前 (usr_…)`（綴りは原文のまま）から取る。`Initialized PlayerAPI "名前" is local` でも本人と分かる。visor-app-vrchat の `VrcLog.cs` はこの行を待っているので、今は本人を見分けられていない
- `[Authentication - ÎÍÌ…]` のように、タグの中に難読化した文字が入る行がある
- 同じ通知が、起動のたび・再接続のたびに何度も `Received Notification` で出る（`not_…` / `frq_…` の ID で重ねない）。送り先の欄が空（`to  of type`）の回もある
- 通知の `created at` は UTC で、形は `MM/dd/yyyy HH:mm:ss UTC`
- グループのお知らせ（`type: group`、本文つき）、投票キックなど（`type: localNotifs`）も通知の行で出る
- **ワールドの名前（`Entering Room`）は、入った行（`Joining wrld_…`）より先に出る**（同じ秒）。`Joining or Creating Room: 名前` は後に出る。VRCX の読み方は Joining のあとに名前が来る前提
- `OnApplicationQuit` は出ていない。最後のログは 11:45 の `Destroying 名前` で止まっている（終了の行がない終わり方。最後の行の時刻で閉じる）
